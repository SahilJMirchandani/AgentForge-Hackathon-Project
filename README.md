# AgentForge — Build, Test, and Deploy AI Agents Without Coding

AgentForge is a no-code platform for creating AI agents from plain-English instructions. Instead of manually designing complex automation workflows, users describe what they want to accomplish and AgentForge turns that intent into a visual, executable agent.

## What AgentForge Does

- **Natural-language agent creation** — Describe a task in plain English.
- **Agent Blueprint** — The LLM converts the request into structured tools, actions, and workflow steps.
- **Visual workflow** — React Flow renders the agent as an interactive node graph.
- **Testing Sandbox** — Generated agents are tested against normal requests, missing information, edge cases, and adversarial prompts.
- **Agent Score** — Evaluates reliability, security, and tool coverage before deployment.
- **Transparent execution** — Shows simulated inputs and outputs at individual nodes so users can understand what the agent is doing.

## Why It Matters

Creating an AI agent should not require deep technical knowledge, and deploying one should not require blind trust. AgentForge brings creation, testing, evaluation, and execution visibility into one workflow, helping users understand and verify an agent before relying on it for real tasks.

## Core Flow

**Natural-Language Prompt → Agent Blueprint → Visual Workflow → Automated Testing → Agent Score → Transparent Execution**
